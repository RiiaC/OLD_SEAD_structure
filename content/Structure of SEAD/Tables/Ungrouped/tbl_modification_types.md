Specifies various modifications or alterations observed in Quaternary or sub-fossils, such as carbonization, mineralization, and fragmentation.

| modification_type_id | modification_type_name           | modification_type_descriptio                                                                                        |
| -------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
|                      | Carbonised                       | Organic matter converted to carbon, most commonly though heating.                                                   |
|                      | Calcified                        | Organic matter replaced by calcium                                                                                  |
|                      | Eroded                           | Surface of fossil has been worn away by physical processes, such as sediment abbraision.                            |
|                      | Fragmented                       | Fossil is not whole.                                                                                                |
|                      | Mineralised (unspecific)         | Organic matter replaced by unspecified mineral(s).                                                                  |
|                      | Pyritified                       | Organic matter replaced by pyrite or marcasite.                                                                     |
|                      | Discoloured (more than expected) | Expected colour of fossil, considering preservation factors, is of an unexpected colour. E.g. as a result of dying. |
|                      | Petrified                        | Organic matter converted to stone by impregnation with silica.                                                      |
|                      | Encased in amber                 | Fossil is encapsulated in a piece of amber.                                                                         |
|                      | Corroded                         | Surface of fossil has been damage by chemical processes.                                                            |
