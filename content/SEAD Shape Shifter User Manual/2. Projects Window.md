>[!info]+ The [SEAD Shape Shifter Projects menu](https://shape-shifter.sead.se/projects) contains the full list of all existing projects.
> You can use this menu to open an existing project, make a copy of someone else's project to experiment with, or create a new project.
> 
> ![[SEAD Shape Shifter Project Window.png]]
> The project window contains a series of tabs necessary to define and map your dataset. From left to right these are: 
> - [[2.1 Entities Pop-up Dialogue box|2.1 Entities]]
> - [[2.2 Graph]]
> - [[2.3 Reconcile]]
> - [[2.4 Validate]]
> - [[2.5 Dispatch]]
> - [[2.6 Data Sources]]
> - [[2.7 Metadata]]
> - [[2.8 Files]]
> - [[2.9 YAML]]

The order of these tabs is based on frequency of use for each section. Therefore the [[2.1 Entities Pop-up Dialogue box|entities dialogue box]] is furthest to the left. However, before beginning work with a project it is recommended that one begin with entering [[2.7 Metadata|metadata]] to record information about the project itself and when/why/by whom it was created. This is especially important as (as of February 2026) all registered users of SEAD Shape Shifter have access to all existing projects.

After the metadata has been recorded, it will be necessary to define your [[7. Glossary#Data Sources|Data Sources]] (see section [[2.6 Data Sources|2.6]]) and/or upload [[7. Glossary#Files|Files]] (see section [[2.8 Files|2.8]]) before starting the data definition and mapping tasks in the [[2.1 Entities Pop-up Dialogue box|Entities]] tab.
