It has three sections:
1. [[4. Schema Explorer Window#Tables|Tables]]
2. [[4. Schema Explorer Window#Table Details|Table Details]] 
3. [[4. Schema Explorer Window#Data Preview| Data Preview]]

# Tables 

In this window you select a [[7. Glossary#Data Sources|Data Source]] from the drop down menu to open the list of tables in that data set. After selecting a data source you select a table within that source by clicking on it (or use the Search Tables box). Then press either "REFRESH ALL" on the upper right side of the screen, to open information from that table in the other two sections. (Alternatively, press just the refresh button within a section to open the information only for that section of the screen)

> [!advice] If there are no data sources showing in the drop down menu, go to the [[3. Data Sources Window|Data Sources]] window and select one and then return to this window

# Table Details

After you have chosen a [[7. Glossary#Tables|Table]] from the list of tables (and refreshed the page) you can see details about that table here. This is particularly useful to see the contents of a "Lookup Table" to determine which types of data in the incoming dataset are already present in SEAD.
#  Data Preview

While the first two options are concerned with the data's [[7. Glossary#Metadata|Metadata]], this window shows the actual data that is associated with the selected [[7. Glossary#Tables|Table]].
