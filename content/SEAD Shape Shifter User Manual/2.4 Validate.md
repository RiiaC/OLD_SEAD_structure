>[!info]+ This is the page where you check your work, and the dataset.
>The **Check Configuration** tab compares your data structure with that of the project's [[7. Glossary#Target Model|Target Model]] to see if all expected data types are present.
>The **Options** tab allows you to change the parameters of the Validation process, including which tests to run, and if they should be run on a random sub-set of the data (faster, best if you suspect that the project isn't complete yet), or all of it (slower, but essential to do, and to pass, before deploying the data into SEAD)
> The **Run YAML Validation** tabs checks the project's YAML for errors
> the **Run Data Validation** tab checks the data itself for issues.
