# SEAD Shape Shifter User Guide
 > [!info] This User Guide is intended to be a comprehensive introduction to using the [SEAD Shape Shifter tool](https://shape-shifter.sead.se/) for transforming and normalising data in preparation for inclusion in the [Strategic Environmental Archaeology Database (SEAD)](https://www.sead.se/).
