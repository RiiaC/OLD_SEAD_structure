# Welcome to The AFL Radiocarbon Dataset Mapping via SEAD Shape Shifter section of this web page

>[!info] This folder contains information pertaining to the ongoing mapping of the AFL Radiocarbon data set to the SEAD database structure. 

This section documents the process of mapping AFL Radiocarbon Dataset to the SEAD database structure prior to importing the data, starting with an example dataset, in the form of a spreadsheet called radiocarbon_Glykou_etal_2021_input.xlsx. This folder tracks my attempts to use [SEAD Shape Shifter ](https://shape-shifter.sead.se/projects/riia-glykou_et_al_2021) to do the mapping, rather than filling in additional sheets of a spreadsheet, as had been the normal procedure before the development of the new SEAD Shape Shifter tool in early 2026.

This dataset is not the most appropriate example for the use of SEAD Shape Shifter, in that it was not a complete dataset upon arrival, lacking information on site location. That information was later added manually to the sites, sites_locations, and locations sheets of the incoming spreadsheet, so the "mapping" for that part of the project was already complete when the dataset was imported into SEAD Shape Shifter, and just needed to be echoed in the entities table here.
